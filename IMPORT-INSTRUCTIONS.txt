SAFE IMPORT INTO YOUR EXISTING GITHUB REPOSITORY
1. In GitHub Desktop, select homepage-redesign-preview, NOT main.
2. Choose Repository > Show in Explorer.
3. Keep the existing repository folder and hidden .git directory. Do not replace or delete .git.
4. Extract this ZIP to a separate temporary folder.
5. Copy the contents of the extracted folder into the root of your existing repository, allowing website files to be replaced.
6. Review the changed files in GitHub Desktop. Stop and inspect if unexpected deletions appear.
7. Commit and push to homepage-redesign-preview.
8. Check the new Vercel Preview deployment and test desktop and mobile layouts.

Do not merge into main or promote the preview to Production until the redesign has been reviewed and approved.
