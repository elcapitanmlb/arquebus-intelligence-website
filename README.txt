DEPLOYMENT
This ZIP contains the website files only, not Git metadata. To use it in the existing GitHub repository:
1. In GitHub Desktop, select homepage-redesign-preview, NOT main.
2. Choose Repository > Show in Explorer.
3. Back up any local-only files you need to preserve.
4. Extract this ZIP to a temporary folder.
5. Copy the ZIP's contents directly into the root of the repository, allowing matching website files to be replaced.
6. Do not delete or replace the repository's hidden .git folder.
7. Review all changed files in GitHub Desktop before committing.
8. Commit and push to homepage-redesign-preview. Check that Vercel creates a Preview deployment.

Do not merge into main or promote the preview to Production until the redesign has been reviewed and approved.
